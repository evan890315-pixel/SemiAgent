# 空洞缺陷（void）— Void 異常批次隔離、分析與處置流程

## 適用範圍
本文件適用於半導體製程中 空洞缺陷 缺陷的 Void 異常批次隔離、分析與處置流程 相關作業。

## 異常定義
空洞缺陷（void）是半導體製程中需要立即處理的缺陷類型。

## 相關根因
- 填洞製程 (Gap Fill) 步進率參數異常
- 製程溫度均勻性不足，局部沉積速率差異大

## 標準處理程序（Void 異常批次隔離、分析與處置流程）
1. 確認異常來源，記錄製程參數與批次資訊
2. 立即 Hold 相關批次，避免持續生產
3. 通知製程工程師與設備工程師
4. 依本 SOP 執行 Void 異常批次隔離、分析與處置流程 相關作業
5. 執行根因分析（RCA）並實施改善措施
6. 驗證改善效果後解除 Hold，填寫異常報告

## 具體操作步驟
1. 確認前驅物 MFC 流量，執行 Gauge 校正
2. 執行腔體溫度 Mapping，調整加熱器功率分布

## 監控指標
- 製程良率（目標 > 90%）
- 缺陷密度（目標 < 0.1 個/cm²）
- 製程能力指數 Cpk（目標 > 1.33）
- Void 異常批次隔離、分析與處置流程 相關指標需每班記錄並分析趨勢

## 異常升級條件
- 良率低於 80% 時立即升級至製程主管
- 連續 3 批次異常需啟動跨部門會議
- 設備安全疑慮時立即停機並通知設備工程師
